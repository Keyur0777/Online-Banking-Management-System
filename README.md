# 🏦 NB Secure Bank System

A secure and feature-rich online banking web application developed using PHP, MySQL, HTML, CSS, and JavaScript.

## 🚀 Features

* 🔐 User Authentication (Login/Register with OTP verification)
* 💸 Fund Transfer System
* 🧾 Transaction History
* 👤 User Dashboard
* 🏦 Admin Panel (Manage users, transactions, loans)
* 💳 Card Management System
* 📊 Analytics Dashboard for Admin
* 🔑 Password Reset & Security Features
* 📧 Email Notifications using PHPMailer

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: PHP
* Database: MySQL
* Libraries: PHPMailer

## 📂 Project Structure

* `/admin` → Admin dashboard & controls
* `/assets` → CSS, JS files
* `/config` → Database configuration
* `/PHPMailer` → Email functionality
* Main files → Login, Register, Dashboard, Transactions

## 🔒 Security Note

Sensitive files such as database configuration and environment variables are not included in this repository for security reasons.

## ⚙️ Setup Instructions

1. Clone the repository
2. Place project in `htdocs` or `www` folder
3. Import the database in MySQL
4. Configure database in `.env` file
5. Run project using localhost
